# Security Policy

## Scope & Target Environments

`ModuleSpoof` demonstrates user-mode memory manipulation and honeypot instrumentation techniques for security research.

| Target Platform | Architecture | Status |
| :--- | :--- | :--- |
| Windows 11 (23H2 / 22H2) | x86_64 | Supported |
| Windows 10 (22H2 / 21H2) | x86_64 | Supported |

## Reporting Security Issues

To report uncontrolled memory corruption or arbitrary code execution vectors, contact:

- **Security Contact**: `adam@networkconnect.org`
- **PGP**: Available upon request.
